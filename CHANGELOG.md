## [1.0.0] - 2026-07-17

### Added

- Installable `general_reference` Python package.
- Traditional and optimised longest-increasing-subsequence implementations.
- Binary search and stable merge sort references.
- Breadth-first and Dijkstra shortest-path implementations.
- Numerically stable streaming statistics.
- Behavioural, numerical and edge-case test coverage.
- Multi-version GitHub Actions quality workflow with coverage enforcement.
- Solution catalogue, contribution guidance, security policy and MIT licence.
- Dependabot, pre-commit hooks, CODEOWNERS and citation metadata.

### Changed

- Reframed the repository as a reusable public reference while preserving the original exploratory notebooks.

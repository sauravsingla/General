# Security policy

## Supported code

The reusable code under `src/general_reference/` and the automation under `.github/` are actively maintained. Historical notebooks are retained for learning and may depend on older third-party libraries.

## Reporting a vulnerability

Please do not publish an exploitable security issue before it has been reviewed. Open a private GitHub security advisory for this repository and include:

- the affected file or function;
- steps to reproduce the issue;
- the practical impact;
- a minimal suggested fix, when available.

Do not include real credentials, personal data, payment data or confidential datasets in a report or reproduction.

## Safe usage

The examples are educational references. Review dependencies, data handling, numerical assumptions and resource limits before adapting them to production systems.

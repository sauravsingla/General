# Benchmark leaderboard

The repository includes a reproducible benchmark leaderboard for the reusable algorithm implementations.

## What it measures

The suite covers sorting, longest increasing subsequence, streaming statistics, string search, edit distance, Fenwick trees, shortest paths and minimum spanning trees. Inputs come from fixed synthetic data and bundled open datasets:

- Iris
- Wine
- Breast Cancer Wisconsin Diagnostic
- Zachary's Karate Club

## Live results

The `benchmarks` GitHub Actions workflow generates a separate leaderboard for Python 3.10, 3.11 and 3.12. Each workflow run provides:

- a ranked Markdown table in the GitHub job summary;
- a downloadable Markdown leaderboard artifact;
- machine-readable JSON containing environment metadata and results;
- 90-day artifact retention.

Timing values are intentionally generated by CI instead of being hard-coded in this document. This prevents results from being presented without their actual execution environment and avoids treating measurements from one machine as universal.

## Ranking rule

Entries are ordered by median wall-clock runtime. Each benchmark receives one warm-up followed by 15 measured runs. The leaderboard reports:

| Field | Meaning |
|---|---|
| Rank | Position by median execution time |
| Benchmark | Algorithm or operation tested |
| Dataset | Open dataset or deterministic synthetic input |
| Input | Number of rows, values, characters, nodes or edges |
| Median | Median runtime in milliseconds |
| Relative | Runtime divided by the fastest benchmark in that run |

The overall ranking compares workload cost, not algorithm quality. The most meaningful direct comparison is between the O(n²) dynamic-programming LIS and O(n log n) patience-sorting LIS implementations.

## Run locally

```bash
python -m pip install -e ".[datasets,dev]"
python benchmarks/run_benchmarks.py --repeats 15
```

Generated files are written to:

```text
benchmark-results/leaderboard.md
benchmark-results/results.json
```

For regression analysis, compare JSON results produced on the same operating system, Python version and comparable hardware.
